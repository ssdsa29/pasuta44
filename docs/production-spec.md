# 制作仕様(確定版)

実測に基づく固定方針。以降の制作とアプリ化はこの仕様に従う。

## 実測データ(RTX 5070 Ti 16GB / RAM 32GB / ComfyUI v0.34.0)

| Krea 2 Turbo t2i | 1024x1536 | 16秒 |

### 動画(HunyuanVideo 1.5 i2v / 720x1088 / 30steps)

| 長さ | フレーム | 時間 | 1秒あたり |
|---|---|---|---|
| 2.04秒 | 49 | 約7分 | 3.4分 |
| 3.04秒 | 73 | 約13分(推定) | 4.4分 |
| 5.04秒 | 121 | **30分14秒** | 6.0分 |

**フレーム数に対して時間は約1.6乗で増える**(Attentionが二乗で効くため)。
短いカットの方が出力1秒あたりでは効率が良い。

VRAM: 121フレームで14.1GB / 16.3GB。OOMなし。

## 確定した設定

### 動画生成

```
解像度   720x1088（縦）
長さ     73フレーム（3.04秒）を基本
         49フレーム（2.04秒）＝テンポの速いコメディ用
         121フレーム（5.04秒）＝感情のピークのみ、2〜3カット限定
ステップ 30
cfg      1（蒸留版のため）
shift    7（720p i2v）
sampler  euler / simple
超解像   使わない
```

### 起点画像

- **動画用キーフレームは作り込みすぎない。** 1024x1536で生成し、
  ワークフロー内の`ImageScale`(lanczos)で720x1088へ落とす
- 2048px超の高精細画像を動画に渡すと、モデルの潜在解像度(16px単位)を
  超えた細部が格子模様として破綻する
- 高解像度の作り込みは**静止画として使う場合だけ**

### 動きのプロンプト

**原則: 動かさない。**

- カメラは固定と明示する: `The camera is completely static on a tripod.`
- カメラと被写体を同じ文で動かさない（同期して不自然になる）
- 表情は段階に分解する: 瞬き → 視線を外す → 戻す → 片側の口角から笑む
- `spreads unevenly` / `a few degrees` / `natural slight asymmetry` を使う
- モデルは「顔を美しく保つ」方向に引き戻す癖があり、俯瞰・煽りの
  カメラ指定は効きにくい。**カメラ制約はプロンプトの冒頭に置く**

### 脱AI（全カット共通で付与）

```
visible skin pores, slightly uneven skin tone, unretouched,
a few loose flyaway strands, natural slight asymmetry,
shot on 35mm film, Kodak Portra 400, film grain, slight halation,
shallow depth of field, slightly imperfect off-center framing
```

避けるもの: スタジオ均一光 / 無地シームレス背景 / 完全な無表情 /
整いすぎた髪 / 左右対称

## 既知の限界

- **16px格子**: HunyuanVideoは16分の1に圧縮した潜在空間で処理するため、
  16px四方が最小単位。それより細かい髪の1本1本は表現できず規則模様になる。
  **モデル構造由来で完全には消せない**。lanczos事前縮小で等倍では見えなくなる
- 1080p超解像は格子を消すが**肌の質感を破壊する**ため不採用
- ステップを50に増やしても格子は減らない（収束の問題ではない）
- 1回の生成は最大121フレーム。長尺は複数カットを繋ぐ

## ライセンス

- **HunyuanVideo 1.5**: 商用可(月間1億ユーザー未満)。EU/英国/韓国は対象外。
  生成物の権利は利用者に帰属。**AI生成であることの明示が必要**
- **Krea 2**: コミュニティライセンス。商用は opensource@krea.ai へ要確認
- オリジナルキャラクターのみ使用。既存IPは使わない

## アプリ化の設計指針

実測から導かれる要件:

1. **動画生成が全体の6割**。ここを止めずに回し続けることが最重要
2. **人間の確認は2箇所だけ**(素材選別・キーフレーム確認)。
   そこで停止して待機できる設計にする
3. **1カット13分**なので失敗コストが小さい。積極的にリトライしてよい
4. カットは独立したジョブとして状態を持ち、**中断・再開可能**にする
5. LLMの役割(日本語→英語Prompt、リトライ判断)はインターフェースとして
   切り出し、後からローカルLLMに差し替えられるようにする

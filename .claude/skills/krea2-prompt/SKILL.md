# Krea 2 Prompt作成

1. まず `docs/krea2-prompting-guide.md` を読む（毎回必ず）。
2. ユーザーの日本語キーワード・指示を、ガイドの「含めるべき要素」の順
   （主題→服装→背景→ライティング→構図→スタイル→カラー）で1段落の英語Promptに展開する。
3. ガイドの禁則を守る: 元の指示の主題・色・位置関係を保持、勝手な要素追加をしない、
   medium指定があれば守る、出力は英文1段落のみ。
4. 画像内に文字を入れる指示があれば、その単語を `"..."` で囲む。
5. 完成したPromptは `prompts/YYYY-MM-DD-<短い題名>.md` に日本語の元指示と一緒に保存する
   （後から参照・派生させるため。記事の運用と同じ）。
6. ユーザーへの提示は「英語Prompt」と「日本語での簡単な内容説明」をセットで返す。

「衣装を赤に」「背景を夜景に」のような差分指示が来たら、直前に保存したPromptを読み込み、
該当箇所だけ書き換えて新しい版として保存する。
